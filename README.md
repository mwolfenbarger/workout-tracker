# Upper/Lower, local version

Your workouts are stored only in your phone's browser storage. Nothing you log is sent anywhere, and no account is needed.

## Put it on your phone (one time)

The app needs to be served from a web address once so your phone can install it. GitHub Pages is free:

1. On github.com, create a new public repository, for example `upper-lower`.
2. Choose **Add file → Upload files**, drag in everything in this folder (keep the `fonts` folder), and commit.
3. Go to **Settings → Pages**, set the source to **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute or two the app is live at `https://<your-username>.github.io/upper-lower/`.

The repository holds only the app's code. Your workout data never goes there.

## Install it

- **iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the link in Chrome, tap the menu, then **Install app** or **Add to Home screen**.

From then on, open it from the home-screen icon. It works offline in the gym. On iPhone the home-screen app keeps its own storage, separate from Safari, so do your logging from the icon.

## Backups

Plan tab → **Export backup** saves a file with all your workouts. **Import backup** merges a backup back in, for example on a new phone.
